# Project_NongWangJai

Dealer intelligence dashboard built with React, Vite, TypeScript, and Tailwind CSS.

## Folder Structure

```txt
.
├── api/                         # Serverless API routes
│   ├── _shared/                  # Server-only helpers used by API routes
│   │   └── cpac-proxy.ts
│   ├── dealers/                  # /api/dealers routes
│   └── orders.ts                 # /api/orders route
├── src/                          # Frontend application source
│   ├── assets/                   # Source assets imported by the app
│   │   └── cpac-logo.jpg
│   ├── components/ui/            # Reusable base UI primitives
│   ├── features/dealers/         # Dealer domain feature
│   │   ├── services/             # Frontend API client, endpoints, normalizers
│   │   ├── dashboard/            # Dashboard app surface
│   │   ├── index.ts
│   │   └── types.ts
│   ├── lib/                      # Shared frontend utilities
│   ├── App.tsx
│   ├── main.tsx
│   └── styles.css
├── index.html
├── package.json
└── vite.config.ts
```

## Important Boundaries

`api/` is server-side code. Files here become API endpoints such as `/api/dealers`, `/api/dealers/usage`, and `/api/orders`. The proxy helper lives in `api/_shared/cpac-proxy.ts` because it uses server environment variables and should not be imported by frontend code.

`src/features/dealers/services/` is frontend code. It contains the browser-side functions that call `/api/...`, normalize API responses, and return data to React hooks.

Current CPAC API note: dealer groups currently use `dealer_id`, while dealer customer usage and sites currently expect `dealer_code` in the same route parameter. The dashboard handles that split in `useDealerDashboardData` until the backend route is normalized.

`src/assets/cpac-logo.jpg` is the single source logo file. Any `dist/assets/cpac-logo-*.jpg` file is generated by `npm run build` and should not be edited manually.

## Dealer Dashboard Structure

```txt
src/features/dealers/dashboard/
├── DealerDashboardApp.tsx        # Dashboard composer and page routing
├── index.ts                      # Dashboard feature export
├── config/                       # Navigation and page metadata
├── hooks/                        # Data loading, filters, theme state
├── layout/                       # Shell, sidebar, header
├── pages/                        # Main dashboard pages
├── charts/                       # Dashboard chart components
├── filters/                      # Filter and picker controls
├── table/                        # Data table, sort header, table columns/types
├── ui/                           # Dashboard-specific UI components
└── lib/                          # Dashboard-only helpers
```

## Common Commands

```bash
npm run dev
npm run build
npm run lint
```

`npm run build` creates `dist/`. That folder is build output, is ignored by git, and can be deleted safely.
